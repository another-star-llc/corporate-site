# 補助金活用レポート（2025年10月末時点）

## 対象補助金
- 足立区：小規模事業者等経営改善補助金
- 足立区：IT・IoT導入補助金
- 国：IT導入補助金2025（インボイス枠 等）

## 各制度の概要とポイント

### 足立区：小規模事業者等経営改善補助金
- 主な対象 … 機械設備・改修・設置工事等、経営基盤改善型投資
- 補助上限・補助率 … 区内調達：上限250万円・補助率2/3／区外調達：上限150万円・補助率1/2
- 準備期日（前段）… 相談予約票＋ドラフト提出：〜2025/12/26（金）
- 本申請・実施… 本申請：〜2026/01/30（金）／実施完了：〜2026/02/27（金）
- 注意 … 汎用PC・タブレット等は対象外となることが多い。

### 足立区：IT・IoT導入補助金
- 主な対象 … IT活用（クラウド／SaaS導入＋委託・開発）／IoT活用（センサー等連携）
- 補助上限・補助率 … IT活用：上限75万円・2/3／IoT活用：上限150万円・2/3
- 準備期日（前段）… 事前相談（中小企業診断士）予約必須
- 本申請・実施… 申請：〜2026/02/13（金）／支払・完了：〜2026/03/19（木）
- 注意 … 汎用PC・スマホ・通信回線整備は対象外。

### 国：IT導入補助金2025
- 主な対象 … 登録ITツール（ソフトウェア・クラウド利用料最大2年）＋役務（導入設定・研修）＋ハードウェア（条件付き）
- 補助上限・補助率 … ソフトウェア等：〜450万円など枠により異なる／ハードウェア（PC・タブレット）は上限10万円・補助率1/2以内（インボイス枠） :contentReference[oaicite:4]{index=4}
- 準備期日（前段）… 支援事業者・登録ツールの選定／見積取得（実質的な前段締切あり）
- 本申請期日… 例：2025/12/02（火）17:00（7次）／交付申請期間：〜2026/01/07（水）17:00
- 注意 … ハードウェア単体申請は不可。ソフトウェアとのセットかつ登録ツールでなければならない。 :contentReference[oaicite:5]{index=5}

## 費目別対応（あなたの想定用途）
| 費目 | 可否・制度 | コメント |
|------|-------------|-----------|
| AI／会計SaaS | 可：国IT導入／足立区IT・IoT | 登録ツールorクラウド、重複不可 |
| API料金 | 可：足立区IT・IoT | “特定業務向けクラウド”扱いにする |

| 技術本 | 否 | 教育・書籍は対象外のケースが多い |
| 交際費（飲食等） | 否 | 補助対象経費として認められないことが一般的 |

### 業務委託費の補助金適用メモ
- 足立区IT・IoT導入補助金 … IT活用枠はクラウド導入＋委託開発のセットを想定しており、要件を満たせば業務委託費（要見積書・契約書）は補助対象。
- 国：IT導入補助金2025 … 登録ITツールを導入する支援事業者経由の設定・開発・研修費が対象。事業者登録とITツール登録が前提。
- 足立区：小規模事業者等経営改善補助金 … 設備投資中心の制度で、業務委託費単独では対象外になりやすいため、本制度での計上は非推奨。

## 重複申請・重複計上の注意
- 同一契約・同一期間・同一費目を複数制度で申請するのは不可。
- 対策：期間をずらす／費目を分ける／制度ごとに役割を明確にする。
- 例：ソフトウェア導入費を国制度／その連携開発・利用料を区制度で、と分離。
